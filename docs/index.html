5-1- Mini Redis 인터랙티브 데모

명령어를 직접 누르고, 우편함(해시맵) · 양손 기차 줄(LRU) · 유통기한 진열대(최소 힙)가 움직이는 모습을 구경하세요

실시간 통역기
아래 ▶ 명세서 예시 자동 실행 버튼을 누르면, 한 단계씩 무슨 일이 일어나는지 한국어로 바로 설명해 드려요!

1. 명령어 실행 (CLI)

지원: SET GET DEL EXISTS DBSIZE KEYS · CONFIG SET maxmemory N · INFO memory · EXPIRE TTL

2. 메모리 상태 (식당 냉장고 용량)

used_memory 0 maxmemory 0 evicted_keys 0 keys 0
maxmemory 가 0이면 무제한입니다. CONFIG SET maxmemory 30 을 입력해 보세요.

3. TTL 최소 힙 (유통기한 진열대 — 가장 급한 키가 맨 위)

EXPIRE 를 설정하면 여기에 나타납니다.

4. LRU 리스트 — 양손 기차 줄: 왼쪽이 최근(1등석 MRU), 오른쪽이 오래됨(퇴거 1순위 LRU)

아직 저장된 키가 없습니다.

5. 해시맵 버킷

노란색 칸 = 같은 우편함 번호에 2개 이상 들어온 해시 충돌(체이닝으로 줄줄이 연결!). 키 개수 / 우편함 수 > 0.75 가 되면 우편함이 2배로 늘어납니다.
