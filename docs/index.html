Mini Redis 인터랙티브 데모

명령어를 직접 입력하고, LRU 리스트 · 해시 버킷 · TTL 힙이 움직이는 모습을 확인하세요

1. 명령어 실행 (CLI)

지원: SET GET DEL EXISTS DBSIZE KEYS · CONFIG SET maxmemory N · INFO memory · EXPIRE TTL

2. 메모리 상태

used_memory 0 maxmemory 0 evicted_keys 0 keys 0
maxmemory 가 0이면 무제한입니다. CONFIG SET maxmemory 30 을 입력해 보세요.

3. TTL 최소 힙 (만료 임박 순)

EXPIRE 를 설정하면 여기에 나타납니다.

4. LRU 리스트 — 왼쪽이 가장 최근(MRU), 오른쪽이 가장 오래됨(퇴거 1순위)

아직 저장된 키가 없습니다.

5. 해시맵 버킷

노란색 칸 = 같은 버킷에 2개 이상 들어온 해시 충돌(체이닝으로 연결됩니다). 키 개수 / 버킷 수 > 0.75 가 되면 버킷이 2배로 늘어납니다.
